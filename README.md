# CRUD Dashboard

A simple full-stack CRUD Dashboard application for managing users.

## Features

- Add users
- View users
- Edit users
- Delete users
- Responsive dashboard UI
- REST API
- JSON database storage

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- CORS

### Database
- JSON
